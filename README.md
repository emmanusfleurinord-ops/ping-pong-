# 🏓 Pong Game - Auto vs Auto

Jogo de Pong clássico feito com HTML5 Canvas e JavaScript puro.  
Os dois lados são controlados por inteligência artificial equilibrada.

🔗 **Jogar online:** [https://emmanusfleurinord-ops.github.io/meu-jogo-pong/](https://emmanusfleurinord-ops.github.io/meu-jogo-pong/)

---

## 🎮 Como funciona

- Os dois paddles são controlados por IA
- A bola muda de ângulo dependendo de onde acerta a raquete (estilo Pong clássico)
- A IA tem um pouco de erro aleatório para não ficar perfeita
- Você pode escolher a dificuldade: **Fácil**, **Médio** ou **Difícil**

---

- HTML5

## ✨ Funcionalidades

- Game Loop com `requestAnimationFrame`
- Inteligência Artificial equilibrada nos dois lados
- Sistema de colisão com ângulo realista
- Aumento de velocidade a cada rebatida
- Seletor de dificuldade
- Erro aleatório na IA (para ficar mais natural)
